# Лабораторная работа: Обработка видео и выделение пикселей по интенсивности

## Описание

В данной лабораторной работе реализована обработка видеофайла на языке Java.  
Основная цель — анализ каждого кадра видео, вычисление матрицы интенсивности и выделение пикселей с низкой яркостью.

## Задачи

1. Загрузить видеофайл и представить его в виде массива кадров.
2. Для каждого кадра:
    - Получить значения каналов **R**, **G**, **B**.
    - Вычислить матрицу интенсивности по формуле:

      ```
      Iv = (R + G + B) / 3
      ```

3. Определить пиксели, интенсивность которых принадлежит первому квантy:
    - Интенсивность < 64

4. Обвести найденные пиксели на исходном кадре:
    - Цвет границы: **красный (255, 0, 0)**

5. Сохранить результат:
    - В виде последовательности кадров (изображений)  
      **или**
    - В виде выходного видеофайла
